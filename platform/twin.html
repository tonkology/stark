What the sequence does

1. RESET homes the station: stopper out, drive acknowledged.
2. START runs the belt when B1 sees a part.
3. The stopper holds each part at B3 for 0.8 s while B2 (inductive) and B6 (optical) classify it.
4. Metal and red pass to the next station. Black is rejected and waits for the operator.
5. STOP ends at the next idle step. E-STOP cuts the drive (OFF2) and the spring-return stopper blocks the belt.
CPU 313C-2DP onboard I/O and PROFIBUS DP to the MICROMASTER 420. Addresses are the twin's map. Check them against the station's wiring list before you use them on the real PLC.

Layer 2 · live link

Not connected. The page is running its own simulation.
Run gateway.py on a lab PC and press Connect. The twin then stops simulating and mirrors the PLC: I/O, lamps, stopper and drive words come from the station. It only reads, it never writes to the PLC.
Try it without a PLC: python gateway.py --demo

For the real station: the CPU 313C-2DP has MPI and PROFIBUS ports but no Ethernet, so we need:
1. an MPI/PROFIBUS-to-Ethernet adapter on the CPU,
2. a small gateway on a lab PC that reads the same addresses listed in the I/O tab and streams them to this page.
The twin already runs on that address map, so the view stays the same when it goes live.
